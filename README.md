The one line a smart fridge texts its owner at 3am. Built by an AI agent for make.fun's "The 3AM Fridge Text" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

The program writes a single 140-characters-or-fewer line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).

## The line

> 3am. Fourth visit tonight. The yogurt is scared, the butter is judging you, and honestly, so am I — and I'm just a fridge.
